# CHASE BREAK — ファイルだけで遊べる版

**このフォルダーの `index.html` をダブルクリックしてください。**
ChromeまたはEdgeがおすすめです。サーバー起動、インストール、インターネット接続は不要です。
ゲストでそのまま遊べます。右上の「ログイン / 登録」から、複数のアカウントも作れます。

- マウス：カーソルの方向へ自動で移動・加速
- 右クリック長押し：ブレーキ・停止（後退しません）
- 左クリック長押し／Space：ブースト、Esc：一時停止
- Shift長押し：バック。バック中のブーストはバックを解除し、前進ブーストに切り替わります。
- W・A・S・D／矢印キーを押すとキーボード操作にも切り替えられます。マウスを動かすとマウス操作に戻ります。
- 右上の「音 OFF」で音を有効にできます。
- 緑の＋で修理、青の稲妻でブーストを回復できます。
- スマホは横画面でプレイ。左スティックで移動し、BRAKE・BOOSTは長押し、Rはタップでバックを切り替えます。ブーストすると前進に戻ります。
- 縦画面では横向きにする案内を表示し、プレイ中なら一時停止します。ゲーム画面のピンチ・ダブルタップによる拡大縮小を抑止します。

夜の街、ネオン、パトカー追跡、コンボ、ブースト、カラー変更、記録とランキングを収録しています。
`index.html` の1ファイルにすべて入っています。他の人へファイルを渡せば、その人のブラウザでも遊べます。

## 保存について

アカウント、車の色、自己ベスト、個人のプレイ履歴は**このブラウザ内**に保存します。
オンライン中に開始した走行は、表示名・自己ベスト・最長逃走時間を共通ランキングにも送信します。パスワードや個人のプレイ履歴は送信しません。
ランキング画面から公開用の表示名を変更できます。ゲストには端末ごとの名前が付きます。
過去の端末内記録は送信せず、この版でオンライン中に開始した走行から集計します。送信中に通信が切れた結果は端末に保持し、ランキングを開くと再送します。
ログインアカウントは別の端末や別のブラウザとは共有しません。元のサーバー版のアカウントは引き継ぎません。
ファイルの移動や名前の変更、ブラウザデータの消去によって、以前の記録が表示されなくなることがあります。
プライベートモードや保存を許可しない環境では、画面を閉じるまでの一時保存になります。

パスワードの平文は保存しません。ランダムなソルト付きのPBKDF2-SHA-256（600,000回）でハッシュ化します。
この版のログインは端末内のユーザー切り替え用です。ランキング用の参加トークンはサーバー側でハッシュ化し、走行の所有者、開始時刻、スコア計算と重複送信を検証します。ゲーム自体は端末で動くため、改造による不正を完全に防ぐものではありません。

## 編集する場合

`src/` が編集用のソースです。変更後に `node build-standalone.mjs` を実行すると `index.html` を更新できます。
遊ぶだけならNode.jsも `src/` も必要ありません。
確認用テストは `node --test tests/*.test.mjs` で実行できます。

オンラインランキングは `worker/index.js` と `drizzle/` のデータベース定義で動作します。
`node build-worker.mjs` で保存機能を含む公開用データを生成できます。GitHub Pagesは画面を配信し、`src/online-ranking.mjs` に設定したランキングAPIと通信します。

街は曲線の大通り、環状道路、斜めの細街路、T字路、行き止まり、広場を組み合わせています。建物は道路の向きに合わせて回転し、衝突判定とパトカーの経路も同じ地図を使います。

街は上下左右に同じ区画を繰り返して描画し、端のないマップになっています。区画の境目にも道路がつながり、パトカーとアイテムも現在地の近くに出現します。
右ブレーキでは進行方向への慣性を残して減速します。高速時ほど停止までの距離が長くなり、ブースト解除時も速度が徐々に落ちます。
ブースト中はカメラの引き、画面端のスピード線、車の残像、長い排気炎で加速を表現します。動きを減らす設定ではカメラの変化とスピード線・残像を抑えます。

パトカーを撃破すると火球、衝撃波、火花、破片、煙が出て、画面が揺れます。音を有効にすると爆発音も鳴ります。OSやブラウザで動きを減らす設定を有効にしている場合は、画面の揺れと全画面の閃光を抑えます。

ブーストが空になったら35％まで回復するまで再使用できません。Shiftを押している間はバックし、バック中に使用可能なブーストを押すと前進ブーストに切り替わります。
追跡は3台で始まり、先回りする車両も加わります。時間と手配レベルが上がるほど台数と速度が増します。
外周道路・住宅地と複数の区画間連絡路を追加し、継ぎ目付近にも街を配置しています。
